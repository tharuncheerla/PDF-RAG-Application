# PDF-Based RAG Application

## Overview
This project is a Retrieval-Augmented Generation (RAG) application built with Python and LangChain. It loads a local PDF document, splits the text into chunks, creates numerical embeddings, and stores them in a local Chroma vector database. It then uses the Groq LLM API to answer user queries based strictly on the retrieved document context.

## Technologies Used
* **Framework:** LangChain
* **LLM:** ChatGroq
* **Embeddings:** HuggingFace (`sentence-transformers/all-MiniLM-L6-v2`)
* **Vector Store:** ChromaDB
* **Document Loader:** PyPDFLoader

## Project Structure
* `main.py`: The core script containing the RAG pipeline.
* `RAG_and_LangChain_Guide.pdf`: The sample document used as the knowledge base.
* `requirements.txt`: Python dependencies needed to run the project.
* `.env`: Environment variables (holds the `GROQ_API_KEY`).
* `chroma_db/`: Local persistent directory for the vector database (auto-generated by the script).
